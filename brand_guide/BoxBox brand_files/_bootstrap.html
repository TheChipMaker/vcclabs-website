04 — USAGE

Logo do & don’t

✓ Do

  • Keep clear space of one pin length (X) around the mark.
  • Use the green “Box” accent on light or dark backgrounds.
  • Use the chip mark alone as app icon, favicon, or LED motif.
  • Reverse to solid white on Ink for HMI and dark contexts.
  • Drop to monochrome when one-color printing demands it.

✕ Don’t

  • Don’t stretch, condense, or rotate the lockup.
  • Don’t change the INDUSTRIES tracking — it spans the wordmark.
  • Don’t recolor the chip into fault red or caution amber.
  • Don’t place the mark on a busy photo without an Ink scrim.
  • Don’t add shadows, glows, or outlines to the mark.

06 — VOICE & TONE

How the brand talks

We sound like a competent engineer who respects your time — precise where it’s safety-critical, plain-spoken everywhere else. Numbers are exact; instructions are verbs.

Precise
State the real number, unit, and standard. Never round away a spec that an installer relies on.
“Requires a 32 A Type-B RCD upstream.” “Needs a suitable safety switch.”
Plain
For the person plugging in their car, use everyday verbs. No jargon, no internals.
“Plug in your car. Charging starts automatically.” “Initiate the EVSE handshake sequence.”
Calm under fault
When something’s wrong, say what happened and the one next action. No alarm, no blame.
“Fault detected. Unplug, then plug back in.” “ERROR! Critical failure — contact support!!”

08 — DOCUMENTS

Document guidelines

Three document types, three readers, one visual system. They differ in depth and surface — never in color meaning or typeface. A4, 18–22mm margins, logo top-left or centered on the cover, JetBrains Mono for every measured value and part number.

END USER

User manual

The person who plugs in their car. Light surface, friendly, minimal electrical detail.

  • Light / paper surface, lots of whitespace
  • LED reference table front and center
  • Plain verbs: “Plug in,” “Unplug to stop”
  • No internals, no bench features
  • Color = the device’s own LED language
ELECTRICIAN

Installation manual

The installer and the inspector. Safety-critical, precise — the doc a certifier reads.

  • Supply spec, breaker, mandatory upstream RCD
  • Wiring terminals, earth / PE, mounting
  • Commissioning + boot self-test as verification
  • Warnings in fault-red callout boxes
  • IEC 61851-1 alignment shown explicitly
ENGINEER / OEM

Technical documentation

An OEM buyer or compliance reviewer. Deepest; may use the dark surface.

  • Architecture, pin map, state machines
  • All four safety subsystems + thresholds
  • Isolation barrier, part numbers, ratings
  • Mono code blocks, green success states
  • Deferred / compliance items flagged
Shared rules Cover: logo + document title (Sora) + product + version + date. Running header: small mono product name left, page number right. Every voltage, current, temperature, and ID in JetBrains Mono. Safety callouts use the semantic colors: red = danger / stop, amber = caution, blue = note / info. Deliver user + installation as PDF (printable, box-ready); keep technical as Markdown in the repo so it versions with the firmware.
